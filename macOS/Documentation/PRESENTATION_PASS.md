# Presentation Pass

This pass focuses on visual/presentation polish rather than gameplay systems.

## Updated areas

- **HUD**
  - upgraded the top status bar to use boxed info panels
  - improved readability for score, high score, episode/hazard count, timer, and lives
  - timer color now escalates from normal to warning to danger as time increases

- **Episode intro card**
  - redesigned the stage-introduction banner to feel more like a TV PSA slate
  - clarified the current episode and reminder text

- **PSA interstitial cards**
  - redesigned the between-stage PSA screen into a stronger structured card with:
    - channel/header strip
    - left information panel
    - right guidance panel
    - clearer score/time-bonus presentation
    - stronger next-step prompt

- **Game-over / final sign-off overlays**
  - upgraded the overlay card layout with header bands, content panels, and cleaner typography
  - differentiated the emergency interruption look from the final sign-off presentation

This pass is meant to make the whole game feel more like a complete retro presentation package and less like a prototype with a few polished screens.
