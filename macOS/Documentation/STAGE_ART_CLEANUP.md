# Full Stage Art Cleanup

This pass gives every campaign backdrop a more intentional, themed treatment so later episodes no longer feel like procedural placeholders.

## Backdrop changes

- **Bathroom:** retained the detailed cabinet and sink treatment from the prior pass.
- **Garage:** added pegboard shelving, chemical bottles, toolbox details, a tire, garage-door bands, and a lock-up sign.
- **Basement:** added pipe collars, storage shelves/crates, boiler detailing, loose bottles, and a storage sign.
- **Kitchen:** added a countertop, cabinet-panel details, refrigerator handles/divider, a toaster, cleaner bottles, and a food-separation sign.
- **Laundry room:** added appliance control panels, layered washer/dryer doors, detergent shelving, a laundry basket, and a cleaner/pod warning sign.
- **Garden shed:** added window muntins, chemical shelving, plants/leaves, tool silhouettes, and a shed-lockup warning sign.
- **Guest house:** added baseboards, detailed cupboard doors, table legs, lamp silhouette, picture frames, and an ask-before-touching sign.
- **Final challenge:** replaced the placeholder target-ring look with a safety-training panel, four hazard stations, warning stripes, and a final challenge sign.

The gameplay platforms remain visually dominant; backdrop art stays subdued so hazards and enemies remain readable.
