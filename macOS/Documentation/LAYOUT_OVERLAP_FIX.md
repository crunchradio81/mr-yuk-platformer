# Layout Overlap Fix

This pass adjusts presentation layout spacing after visual overlap issues were identified in the PSA interstitial screen.

## Problems addressed

- the lower score/time-bonus band visually overlapped the main content boxes
- the bottom prompt band sat too close to the outer frame
- the left/right content boxes felt vertically cramped

## Changes made

- increased the PSA interstitial card height slightly
- raised and slightly shortened the left and right information panels
- reduced the logo size a bit inside the left panel
- moved the score/time-bonus band downward so it clearly clears the panel boxes
- moved the phone, emergency, and prompt bands for cleaner spacing
- nudged several text elements for better vertical rhythm

The goal is a cleaner, clearly separated faux-broadcast layout.
