# Title Screen PSA Pass

This pass removes the sprite-sheet showcase from the attract/title screen and replaces it with a faux 1990s poison-control PSA presentation.

## Changes

- removed the `RetroSpriteSheet` preview from the title screen
- added a subtitle line emphasizing the faux local-TV PSA framing
- added a warning banner across the top of the screen
- added three PSA-style information cards:
  - Medicine Safety
  - Stick on a Yuk
  - Poison Help
- retained the control legend, high score, and Poison Help phone number

The goal is for the attract screen to feel more like a piece of period educational television rather than a development-art showcase.
