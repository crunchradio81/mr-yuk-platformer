# Title Screen Layout Fix

This pass makes a small visual/layout adjustment to the attract screen.

## Problem addressed

The blinking `PRESS RETURN TO START` text sat directly on top of the lower green TV-frame border, causing it to feel clipped.

## Change made

- added a small center **bottom cutout** in the lower border area
- moved the start prompt slightly upward
- added a subtle horizontal accent line above the cutout so the opening looks intentional

This keeps the attract screen readable while preserving the faux CRT/TV frame look.
