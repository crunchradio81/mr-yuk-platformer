# Development Roadmap

## Completed

- native macOS 14 / arm64 SpriteKit shell
- eight complete single-screen PSA episodes
- platform, ladder, jump and enemy navigation
- atlas-derived pixel-art player, enemies, hazards and sticker art
- dual-purpose hazard-seal / sticker-toss action
- enemy stun behavior
- state-driven animation handling
- CRT/VHS presentation layer and PSA interstitials
- score, lives, persistent high score, chain multiplier and time bonuses
- pause/resume, music toggle and restart controls
- original retro sound effects and original looping chiptune-style theme
- screen shake, particles and impact feedback
- responsive jump buffering / coyote time

## Strongest remaining upgrades

The project is now a fuller eight-episode release candidate rather than a bare vertical slice. The strongest remaining upgrades would be environment-triggered cabinet/shelf traps, more stage-specific mechanics, richer hand-cleaned animation frames, controller support, settings/accessibility, saveable score tables, and eventual signing/notarization.


## Phase 6 — release-candidate presentation pass — complete

The current build cleans the core branding assets, including transparent Mr. Yuk logo presentation and regenerated app icons, while deliberately leaving signing and bundle-id concerns for local project setup.


## Phase 7 — full presentation pass — complete

The current build applies a more cohesive faux-1990s PSA presentation across the HUD, interstitials, and end-state screens.


## Phase 8 — balance + content expansion — complete

The release-candidate campaign now spans eight episodes with a tuned full-run difficulty curve and a final mixed-hazard challenge.
