# Title and Backdrop Cleanup

This pass addresses two presentation issues reported during playtesting.

## Title screen cleanup

The lower title-screen text stack still felt crowded, with the help-number line and the start prompt appearing too close together.

### Changes
- moved the control, high-score, and help-number lines slightly upward
- reduced those text sizes slightly
- widened the lower border cutout
- adjusted the start prompt position and size for clearer separation

## Bathroom backdrop cleanup

The first stage backdrop still contained two large placeholder-looking shapes: a top rectangle and a bottom circle.

### Changes
- replaced the oversized medicine-cabinet placeholder with a more detailed cabinet treatment using shelves and bottle silhouettes
- replaced the large sink ellipse with a flatter sink/counter treatment and a smaller basin detail
- kept the bathroom theme intact while removing the obviously placeholder look
